What changed

  • The disc, bold "not installed" title and the 190-character paragraph are gone. Status is a quiet muted badge in the header; the title says the action.
  • One nested container: the Build tile, key left, control right. Its description now states the differentiator (flash) for the picked build and keeps the irreversibility clause visible.
  • The data cost moved to the footer's left edge, beside the button it applies to. The commit sits on the bottom-right edge, the way the installed Connection card commits.
  • "Check again" is an icon button in the header. Install is the only primary on the card.
  • While installing, the transcript replaces the Build tile and the footer status says what is happening. On failure the notice sits directly above the transcript, and the button becomes "Try again".
  • Sizes (~6 MB / ~12 MB) are placeholders: the backend does not report download size or free flash yet. Treat that as an open question.
