# Feature Notes

Per-feature deep-dives extracted from `CLAUDE.md` to keep the always-loaded prompt small. Read these on demand when working on a specific feature.

Login rate limiting (the lockout ladder behind `auth/login.sh` and `auth/check.sh`) lives in [`../reference/auth-rate-limiting.md`](../reference/auth-rate-limiting.md); it is not a feature doc. The pre-auth `/` splash and its public endpoints (`public/overview.sh`, `public/hostname.sh`, `public/units.sh`) are documented in [`../reference/overview-splash.md`](../reference/overview-splash.md).
